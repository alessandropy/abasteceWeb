# Abastece+ | Plataforma B2B de Abastecimiento Inteligente Creado por alessandro S

Abastece+ es una experiencia digital SaaS y e-commerce B2B de alta gama diseñada específicamente para pequeños y medianos comerciantes (bodegas y negocios locales en Perú). Su objetivo es transformar el abastecimiento tradicional en un flujo rápido, inteligente y autónomo.

#Características Principales (Rediseño UX/UI)
- Command Center Interactivo: Navegación superior flotante fluida y moderna inspirada en estándares internacionales de software (Linear, Stripe, Arc).
- Workspace Inteligente: Visualización de productos en un sistema de tarjetas editoriales de alta profundidad con efectos de hover magnético y zoom suave.
- Catálogo Categorizado con Imágenes Dinámicas: Secciones limpias con miniaturas por categorías (Abarrotes, Bebidas, Lácteos, Limpieza, Artículos de tienda).
- Control Predictivo de Stock y Lotes: Widgets vivos e indicadores de ahorro en tiempo real.
- Asistente de IA (HubBot): Simulador de chat comercial para resolver dudas sobre despacho y descuentos.
- Sistema de Descuento Corporativo: Activación automática de beneficios al superar S/ 250 en pedidos.
- Experiencia de Pago y Checkout: Selección de ventanas de despacho en Lima y métodos de pago flexibles (tarjeta o contra entrega).

## Tecnologías Utilizadas
- HTML5 semántico y accesible.
- CSS3 moderno (Variables CSS, Flexbox/Grid, Glassmorphism, animaciones fluidas).
- JavaScript (Vanilla ES6+) con arquitectura orientada a estados locales (`state management` y sincronización con `localStorage`).
- Tipografía optimizada: Plus Jakarta Sans y JetBrains Mono.

## Cómo Ejecutar el Proyecto Localmente
1. Clona o descarga el repositorio en tu computadora.
2. Abre la carpeta del proyecto en tu entorno de desarrollo (como Visual Studio Code).
3. Utiliza una extensión de servidor local (por ejemplo, **Live Server**) para abrir el archivo `index.html`.
4. Ingresa a la plataforma utilizando las credenciales de demostración:
   - **Usuario:** `demo`
   - **Contraseña:** `1234`
